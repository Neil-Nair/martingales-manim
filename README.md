# Martingales: Get Even or Get Even Worse

Code behind a talk on martingales, from fair coin games and the doubling strategy to Brownian hitting times and Black-Scholes. The talk won **Best in College** and was nominated for the **departmental speaking award**.

The repository has two halves:

| | Folder | What it is |
| --- | --- | --- |
| **Technical** | [`simulations/`](simulations) | The stochastic simulations: random walks, Brownian motion, stopping times, and Monte Carlo checks of every result in the talk against its closed form. |
| **Communicative** | [`animations/`](animations) | The Manim animator: one scene per cue in the script, rendered to short clips for the slides. The scenes draw paths generated by `simulations/`. |

```
.
├── simulations/
│   ├── random_walk.py   walks, exit times, gambler's ruin, doubling strategy
│   ├── brownian.py      Brownian paths, first hitting times, Lévy distribution
│   └── verify.py        Monte Carlo vs theory  (python -m simulations.verify)
├── animations/
│   ├── martingales_animations.py   17 Manim scenes
│   └── manim.cfg                   1080p60, white background
└── requirements.txt
```

## The mathematics

**Fair games and the doubling strategy.** A fair coin game has zero expected profit, and doubling your bet after every loss doesn't change that once there is a betting limit: you win a little almost always and lose a lot occasionally.

**Martingales and the optional stopping theorem.** A martingale is a process whose expected next value, given the past, is its current value. The optional stopping theorem says that stopping a martingale at a suitable random time keeps its expectation: E[X_T] = E[X_0].

**Hitting probabilities.** A walk started at x between barriers a < x < b hits b first with probability (x − a)/(b − a). The talk derives this twice, from a first-step balance equation and directly from optional stopping.

**Expected hitting times.** Since X_n² − n is also a martingale, optional stopping gives the expected exit time E[T] = (x − a)(b − x).

**Brownian motion.** Rescaling a random walk by √n and taking finer steps gives Brownian motion (Donsker's theorem).

**Brownian hitting times.** Optional stopping applied to the exponential martingale exp(αB_t − α²t/2) gives the Laplace transform E[e^(−λT_a)] = e^(−a√(2λ)), which identifies the first hitting time of level a as Lévy distributed.

**Finance.** An option viewed as a hitting problem, and the Black-Scholes formula as optional stopping with a risk-free rate.

## Technical side: simulations

Requires Python 3.9+ and NumPy (matplotlib for plots).

```bash
pip install -r requirements.txt
python -m simulations.verify           # theory vs simulation tables
python -m simulations.verify --plot    # plus histograms
```

Sample output (20,000 simulations each, 95% intervals):

```
Random walk from 3, barriers at 0 and 10
  P(hit upper first)       theory    0.3000   simulated    0.3002 ± 0.0064
  E[T]                     theory   21.0000   simulated   20.9881 ± 0.2761

Brownian first hitting time of a = 1.0 (dt = 0.001)
  P(T_a <= 1.0)            theory    0.3173   simulated    0.3159 ± 0.0064
  E[exp(-0.5 T_a)]         theory    0.3679   simulated    0.3680 ± 0.0045
```

The Brownian hitting-time simulation uses a Brownian bridge correction, so crossings between time-grid points are not missed and T_a isn't biased upward.

The functions are usable on their own:

```python
import numpy as np
from simulations import simulate_exit, prob_hit_upper_first

rng = np.random.default_rng(0)
hit_upper, T = simulate_exit(start=3, lower=0, upper=10, n_sims=10_000, rng=rng)
print(hit_upper.mean(), prob_hit_upper_first(3, 0, 10))
```

Every sampler accepts `rng` (a NumPy `Generator`, recommended) or `seed`. The animation scenes use `seed`, which keeps the exact paths shown in the talk reproducible.

## Communicative side: animations

Requires [Manim Community Edition](https://docs.manim.community/) with FFmpeg, and a LaTeX distribution (MiKTeX, TeX Live or MacTeX) for the equations.

Run from the repository root:

```bash
manim -pql animations/martingales_animations.py S4_NumberLine   # one scene
manim -pql animations/martingales_animations.py                 # every scene
```

`-ql` is 480p for previews, `-qm` 720p, `-qh` 1080p for the final export. Drop `-p` to skip opening the video. Clips are written to `media/videos/martingales_animations/<quality>/<SceneName>.mp4` (not tracked in git).

| Section | Scenes |
| --- | --- |
| 1 Title | `S1_TitleReveal` |
| 2 Fair games | `S2_CoinLabels`, `S2_SingleRandomWalk`, `S2_DoublingTable` |
| 3 Martingales | `S3_RandomWalkWithMean`, `S3_ConservationLawInset`, `S3_RandomWalkDefinition` |
| 4 Hitting probabilities | `S4_NumberLine`, `S4_MartingaleWayPanel` |
| 5 Spread | `S5_SpreadGrowth` |
| 6 Expected hitting time | `S6_ExpectedTimeDerivation` |
| 7 Brownian motion | `S7_RandomWalkToBrownian`, `S7_BrownianProperties` |
| 8 Brownian hitting times | `S8_BrownianHittingSetup`, `S8_ExponentialMartingale` |
| 9 Finance | `S9_Finance` |
| Close | `Closing_SummaryLines` |

The shared colour palette is at the top of the scene file, and each scene opens with named constants (font sizes, step counts, seeds) for tweaking layout without touching the animation logic.
